<summary><b>⚙️ Snake not rendering? Setup note</b></summary>
<br/>

This animated snake isn't a static image — it's generated by a GitHub Action
(<a href="https://github.com/Platane/snk">Platane/snk</a>) that runs on a schedule
and pushes an SVG to an `output` branch. If it's blank, the action likely hasn't been
added to the `thanmaydr0/thanmaydr0` repo yet. A minimal workflow:

```yaml
name: generate contribution snake
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch: {}
  push:
    branches: [ "main" ]

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: thanmaydr0
          outputs: dist/github-contribution-grid-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

<h2 align="center">📘 GLOSSARY.LOG // TERMS I USE A LOT</h2>

<table align="center" width="90%">
<tr><th align="left">Term</th><th align="left">What I mean by it</th></tr>
<tr><td>Agentic system</td><td>An LLM-driven pipeline that plans steps, calls tools, and acts — not just single-turn Q&A</td></tr>
<tr><td>MLOps</td><td>The engineering discipline of deploying, monitoring, and maintaining ML systems in production</td></tr>
<tr><td>Zero-trust</td><td>Security model where nothing is implicitly trusted, even inside the network perimeter</td></tr>
<tr><td>Event-driven architecture</td><td>System design where services react to events/messages rather than direct calls</td></tr>
<tr><td>Dead-letter queue</td><td>Holding area for messages/jobs that failed processing, for later inspection or retry</td></tr>
<tr><td>Idempotency</td><td>Property where retrying the same operation produces the same result — critical for safe retries</td></tr>
<tr><td>Backpressure</td><td>Mechanism for a system to signal "slow down" upstream instead of silently dropping work</td></tr>
<tr><td>Tool calling</td><td>An LLM's ability to invoke external functions/APIs mid-conversation to fetch data or take action</td></tr>
<tr><td>Observability</td><td>Logs, metrics, and traces good enough to answer "why did this break" without guessing</td></tr>
